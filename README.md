ShopVerse - E-Commerce Web Application

A full-stack e-commerce platform with product management, shopping cart, order tracking, and role-based access control (Admin/User).
Built as a comprehensive learning project for full-stack development.

 Features
Core Functionality
- Product Catalog - Browse products with prices and icons
- Shopping Cart - Add/remove items, adjust quantities, and checkout
- Order Management - Track order status (Pending → Shipped → Delivered)
- User Authentication - Login/Signup with role-based access
- Role-Based Access - Admin and User roles with different permissions
- 
Admin Features
- Product Management - Add new products to the catalog
- Order Oversight - View all user orders
- Order Status Updates - Change order status (Pending/Shipped/Delivered)
- Order Management - Clear all orders when needed

User Features
- Product Browsing - View all available products
- Cart Management - Add/remove products, adjust quantities
- Checkout - Place orders with cart contents
- Order History - View personal order history with status
  
User Experience
- Clean, modern UI with smooth transitions
- Real-time cart updates
- Toast notifications for user feedback
- Responsive design for desktop, tablet, and mobile
- Intuitive role-based interface

 Tech Stack
Frontend
- HTML5 - Semantic markup
- CSS3 - Custom styles with Flexbox and CSS Grid
- JavaScript (ES6+) - Vanilla JS for DOM manipulation
- Font Awesome - Icon library
- Google Fonts (Inter) - Typography

Backend (Simulated)
- In-memory data store (demonstration)
- Client-side state management
- No external dependencies required

 Installation & Setup

 Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Local development server (VS Code Live Server, Python HTTP Server, etc.)
